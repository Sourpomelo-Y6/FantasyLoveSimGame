# リリースチェックリスト

配布候補を作る前に、次を順番に確認する。

## プロジェクト

- `ProjectSettings/ProjectVersion.txt` とREADMEのUnityバージョンが一致している
- Unity Consoleにコンパイルエラーがない
- EditMode Testが全件成功し、失敗が0件
- `FantasyLoveSim > Validation > Run All Validations` の警告を確認済み
- TitleSceneから新規開始、ロード、MainScene、EndingSceneへの遷移を確認済み

## プレイ回帰

- 会話、行動、予定設定・変更・キャンセル、テンプレート保存・適用
- 訓練、スキル取得・編成、探索、戦闘、アイテム、ショップ
- 状態・実績、メッセージログ、スチル回想
- 複数スロットのセーブ・ロードと、再起動後の復元
- ゲームイベントの一度だけ表示と完了報酬

## 表示・音響

- 対象解像度で文字、スクロール、マスク、Safe Areaが崩れない
- 日本語TMP Font Assetをローカル設定して欠字がない
- タイトル・音響機能の実装後は、フィクション表記がタイトル画面で読める
- タイトル・音響機能の実装後は、BGM、SE、ボイスが未設定でも例外が発生しない
- オプション実装後は、音量、ミュート、自動再生設定が再起動後も維持される

## 配布物・権利

- `AssetCredits.md` に採用素材の作者、出典、ライセンス、配布可否が記録されている
- テスト画像、未許諾素材、ローカルフォント、生成TMP Font Asset、不要なセーブを含めない
- README、ユーザー説明書、スクリーンショットが現在のUIと一致している
- ビルドを新しいフォルダで起動し、開発環境に依存しないことを確認する
