# セーブデータと端末共通ファイル

ゲーム進行のセーブと、端末全体で共有する設定を分離して扱う。

## ゲームセーブ

各セーブスロットには、選択ヒロイン、日付・時間、好感度、所持品、衣装、予定、
訓練・戦闘実績、スキル、既読イベント、解放済みスチルなど、その周回固有の進行を保存する。
ロード時は保存済みヒロインIDをタイトル画面の現在選択より優先する。

## 端末共通データ

次の情報はゲームセーブと分離し、別スロットからも利用できる。

- 7日／30日の名前付き予定テンプレート
- 将来追加するBGM・SE・ボイス音量、ミュート、ボイス自動再生
- その他、周回進行ではなく利用者の環境に属する設定

保存先は `Application.persistentDataPath` を基準とする。OSや実行環境で実パスが異なるため、
文書やコードで特定ユーザーの絶対パスを前提にしない。

## 開発時の注意

- セーブ形式を変える場合はバージョン番号と移行処理を追加する
- 未追加フィールド、null、空リストは安全な初期値へ正規化する
- テンプレートなど端末共通データの削除は、ゲームセーブ削除とは別操作として扱う
- バグ報告用データには個人名やローカルパスが含まれていないか確認する
- セーブ、テンプレート、ログなど実行時生成ファイルは通常Gitへコミットしない

配布前は、新規環境、旧セーブ移行、複数スロット、端末共通設定の共有をそれぞれ確認する。
