# 画面表示・解像度対応計画

## 目的

画面解像度や縦横比が変わっても、主要UIが重ならず、画面外へ欠けず、
文字・スクロール・選択状態を確認できる表示を目指す。
当面はPC向け横画面を対象とし、スマートフォン向け縦画面への組み替えは別対応とする。

## 現在の設定

`ProjectSettings/ProjectSettings.asset` のStandalone初期解像度は `1920 x 1080`。
ウィンドウは現在リサイズ不可で、対応アスペクト比の設定自体は
`4:3` / `5:4` / `16:10` / `16:9` / その他を許可している。

SceneのCanvas設定は次の状態。

| Scene | UI Scale Mode | Reference Resolution | Match |
| --- | --- | --- | --- |
| `TitleScene` | Scale With Screen Size | 1920 x 1080 | 0.5 |
| `MainScene` | Scale With Screen Size | 1920 x 1080 | 0.5 |
| `SampleScene` | Scale With Screen Size | 1920 x 1080 | 0.5 |
| `EndingScene` | Constant Pixel Size | 800 x 600 | 0 |

`EndingScene` だけ基準が異なるため、解像度対応を実装するときは
`Scale With Screen Size`、`1920 x 1080`、`Match Width Or Height = 0.5` へ揃えることを
第一候補とする。実際のScene変更はUnity Editor上で表示を確認してから行う。

## 基本方針

- 基準デザインは `1920 x 1080`、横画面、16:9とする
- Canvasは原則 `Scale With Screen Size`、基準 `1920 x 1080`、Match `0.5` に統一する
- 主要パネルは固定座標だけに依存せず、適切なAnchor、Pivot、Layout Groupを使う
- 背景やスチルは縦横比を維持し、余白または端の切り取り方を画面ごとに決める
- 操作ボタン、本文、スクロール領域は画面端から余白を取る
- ScrollRectの表示物はViewportとMaskで領域外を表示しない
- 長い名前や本文は、最大文字数、折り返し、縮小、スクロールのどれで扱うかを明示する
- PC版でも将来のSafe Area対応を妨げないよう、重要表示を画面の最外周へ固定しない

## 確認する解像度と画面比率

最低限、Game Viewで次を確認する。

| 解像度 | 比率 | 主な確認目的 |
| --- | --- | --- |
| 1920 x 1080 | 16:9 | 基準表示 |
| 1280 x 720 | 16:9 | 小さい横画面と文字の可読性 |
| 2560 x 1440 | 16:9 | 高解像度での拡大 |
| 1920 x 1200 | 16:10 | 縦方向の余白 |
| 1600 x 900 | 16:9 | 一般的なウィンドウ表示 |
| 1024 x 768 | 4:3 | 横幅不足、重なり、左右欠け |

21:9などの横長画面は、ゲーム画面を無理に横へ引き伸ばすより、
16:9の安全領域を保って左右へ背景または余白を表示する方式を候補とする。
対応対象に含めるかは配布プラットフォーム決定時に確定する。

## 画面別の確認項目

### タイトル

- ロゴ、ヒロイン、New Game、Continue、フィクション表記が重ならない
- 背景の重要部分が比率変更で切れない
- セーブスロットやキャラクター選択を開いても画面外へ出ない

### メイン画面

- キャラクター立ち絵、メッセージ、行動ボタン、GenreButtonAreaが重ならない
- 名前、HP、MP、状態表示が狭い画面でも判別できる
- 状態、実績、ログ、回想などのオーバーレイが画面内に収まる

### 予定・訓練・スキル

- 週間・月間セルとSelectedDayAreaが重ならない
- 予定テンプレートの入力欄とボタンが欠けない
- 訓練画像、セリフ、ログ、スキルツリーノードを操作できる

### 戦闘・ショップ

- プレイヤー、ヒロイン、敵のHP・MP・名前・状態が重ならない
- スキル、アイテム、対象選択パネルが画面外へ出ない
- ScrollRect外の項目がマスクされ、選択色が確認できる

## 将来のオプション

プレイヤーが変更できる画面設定を追加する場合は、次を候補とする。

- ウィンドウ／フルスクリーン切り替え
- 解像度一覧
- 必要ならUI拡大率

設定はゲームのセーブスロットではなく端末共通設定として
`Application.persistentDataPath` に保存する。
起動環境で使えない解像度が保存されていた場合は、安全な既定値へ戻す。

## 実装順

1. `EndingScene` を含む全Canvasの設定を確認・統一する
2. 主要画面を上記6解像度で目視確認し、崩れを一覧化する
3. Anchor、Layout Group、Content Size Fitter、Maskの問題を画面単位で直す
4. 背景・スチルの横長／4:3表示方針を確定する
5. 必要になった段階で画面設定UIと端末共通保存を実装する
6. HTMLユーザー説明書の動作環境と画面設定へ反映する

## 完了条件

- 対象解像度で主要操作が画面外へ出ない
- テキスト、画像、選択色、スクロール領域に重大な重なりがない
- 16:9以外でも重要な情報と操作が欠けない
- Scene間でCanvasの拡縮方針が一致している
- 解像度設定を追加した場合、再起動後に復元され、不正値から安全に復帰できる
