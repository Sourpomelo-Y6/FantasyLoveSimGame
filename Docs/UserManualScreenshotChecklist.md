# ユーザー説明書スクリーンショット確認表

HTML説明書の画像は、UIが確定した画面だけを撮影し、
`Docs/UserManual/images/` に用途が分かる英数字名で保存する。

## 撮影対象

- タイトル画面、キャラクター選択、新規開始、Continue
- メイン画面の各表示領域と行動ボタン
- 会話ジャンル、選択肢、メッセージ送り
- 週間・月間予定、選択日、キャンセル、予定テンプレート
- 訓練、スキルツリー、戦闘スキル編成
- 探索、戦闘、スキル、アイテム、対象選択
- ショップ、状態・実績、メッセージログ、スチル回想
- セーブ、ロード、Options

## 画像ごとの確認

- 現在のボタン名と本文の説明が一致する
- マウス位置、選択色、注目箇所が意図した状態になっている
- Console、デバッグ表示、個人情報、ローカルパスが写っていない
- 未許諾画像・フォント・音声由来の表示を含まない
- 必要なら番号、枠、矢印を付け、本文側にも同じ番号を書く
- 画像には内容を説明する `alt` とキャプションを設定する
- PC表示と狭い画面で画像がはみ出さない

## 更新ルール

UIの配置、名称、操作順、状態色を変えた場合は、対応画像と本文を同じ変更で更新する。
単なる装飾変更で操作説明へ影響しない場合も、古い画像が誤解を招かないか確認する。
制作途中の `Assets/Images` 内テスト画像を、そのまま説明書画像としてコミットしない。
